05 · ABOUT THE PROJECT

技术方案与使用边界

一个纯前端、零依赖、可离线运行的轻量级智能分类演示系统。

技术方案

  • 纯前端实现：HTML5 + CSS3 + 原生 JavaScript，无需后端、数据库或 API 密钥。
  • 混合分类算法：同义词归一化、关键词规则优先匹配、多项式朴素贝叶斯文本分类（含拉普拉斯平滑）。
  • 可解释输出：给出类别、匹配参考值、判断依据、投放建议与后续处理方向。
  • 本地存储：查询历史保存在浏览器 localStorage，不上传服务器。
  • 响应式布局：一次开发，适配桌面与移动端。

使用边界与说明

  • 本系统提供通用分类参考，实际投放请以所在地最新生活垃圾分类目录和管理要求为准。
  • 界面中的“匹配参考值”为系统内部展示指标，不等同于经独立测试集验证的模型准确率。
  • 内置样例语料规模较小，对复杂描述、方言、复合材料与多物品混合输入的识别能力有限。
  • 当前版本仅处理文本，未接入图像识别；各地垃圾分类规则存在差异。
