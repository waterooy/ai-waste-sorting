# 绿循 · AI 智能垃圾分类与资源回收系统

面向垃圾分类科普与教学演示的静态网页作品。纯前端实现（HTML + CSS + JavaScript），无需后端、数据库或 API 密钥。

## 功能

- **智能分类查询**：输入物品名称，输出类别、匹配置信度、判断依据、投放建议与后续处理方向。
- **分类流程**：文本预处理 → 同义词归一化 → 关键词规则优先匹配 → 多项式朴素贝叶斯文本分类（含拉普拉斯平滑）。
- **四分类指南**：可回收物、厨余垃圾、有害垃圾、其他垃圾的定义、常见例子与投放提示。
- **知识挑战**：10 道题随机抽 5 道，每题 20 分，答后即时反馈。
- **资源循环流程**：展示从源头分类到分类收运、资源化/无害化处理与再生利用的路径。
- **本地查询历史**：保存在浏览器 localStorage，不上传服务器。

## 文件结构

```
index.html   页面结构与内容
styles.css   深空绿科技主题、玻璃拟态、响应式样式
app.js       分类算法、答题逻辑、交互
.nojekyll    确保 GitHub Pages 正确处理静态文件
preview_*.png 本地渲染预览图（可安全删除）
```

本项目通过 GitHub Pages 部署，发布源为 `main` 分支根目录（`/`）。

线上地址：https://waterooy.github.io/ai-waste-sorting/

## 说明

- 本系统提供通用分类参考，实际投放请以所在地最新生活垃圾分类目录和管理要求为准。
- 界面中的“匹配置信度”为系统内部展示指标，不等同于经独立测试集验证的模型准确率。
- 内置样例语料规模较小，对复杂描述、方言、复合材料和多物品混合输入的识别能力有限。
