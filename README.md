# 绿循：AI 智能垃圾分类与资源回收系统

本项目是《人工智能基础与应用》课程实践作品，面向生活垃圾分类科普与教学演示场景。

## 1. 项目功能

- 垃圾名称文本查询与分类建议
- 四分类知识卡片与投放建议
- 互动分类知识挑战
- 查询次数本地统计
- 垃圾分类与资源循环流程说明
- 适配桌面端与移动端

## 2. 技术实现

- HTML5：页面结构
- CSS3：响应式布局与视觉样式
- JavaScript：交互逻辑、分类知识库与本地数据存储
- 算法：同义词归一化、关键词规则优先匹配、多项式朴素贝叶斯文本分类（浏览器端运行）

**算法边界说明：** 当前版本是教学演示型轻量文本分类原型，使用内置小规模样例语料，不是经过大规模数据训练的通用模型，也不具备真实图像识别能力。分类结果仅供学习参考；实际投放请以所在地最新分类目录为准。

## 3. 本地运行

无需安装依赖。下载或克隆项目后，直接用浏览器打开 `index.html` 即可。

也可在项目目录运行一个简单静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 4. GitHub Pages 部署（课程要求）

### 第一步：创建仓库
1. 登录 GitHub。
2. 点击右上角 `+` → `New repository`。
3. 仓库名称建议填写 `ai-waste-sorting`。
4. 选择 `Public`，勾选添加 README（如果已准备本项目 README，也可不勾选）。
5. 点击 `Create repository`。

### 第二步：上传项目文件
将本项目压缩包解压，把以下文件直接放到仓库根目录（不要只上传 zip）：

- `index.html`
- `styles.css`
- `app.js`
- `README.md`
- `.nojekyll`

在仓库页面点击 `Add file` → `Upload files`，拖入上述文件，填写提交说明，例如 `Initial website release`，点击 `Commit changes`。

### 第三步：开启 GitHub Pages
1. 进入仓库 `Settings`。
2. 左侧选择 `Pages`。
3. 在 `Build and deployment` 中，`Source` 选择 `Deploy from a branch`。
4. `Branch` 选择 `main`，目录选择 `/(root)`。
5. 点击 `Save`。

### 第四步：获取访问链接
等待 GitHub Pages 构建完成，页面会显示站点地址，通常格式为：

`https://你的GitHub用户名.github.io/ai-waste-sorting/`

打开链接检查页面和交互功能。若未立即生效，可等待几分钟后刷新。

### 第五步：填写课程报告
将真实仓库地址和 GitHub Pages 网页地址分别填入实验报告封面/成果展示部分。不要提交示例占位链接。

## 6. 注意事项

- 查询历史保存在当前浏览器的 `localStorage` 中，不会自动同步到其他设备。
- 当前项目不调用外部 API，不需要密钥，也不上传用户输入。
- 分类规则可能因城市而异，演示结果不能代替当地管理部门的正式目录。
